## 🚀 How to Open

### Option 1 (Instant):
Simply double-click `index.html` to open it in Google Chrome, Microsoft Edge, or any modern browser.

### Option 2 (Local Server):
Double-click `start.bat` or run:
```bash
python -m http.server 8085
```
and open `http://localhost:8085` in your browser.
